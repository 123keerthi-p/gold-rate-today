✨ Features

- 🪙 **22 Karat & 24 Karat** gold rate display with live price cards
- 📍 **City-wise gold rate table** — Today vs Yesterday with price change indicator (▲▼)
- 🗓️ **Yesterday's gold rate** — 1g, 8g, 10g, 100g breakdown
- 📊 **Historical gold rate table** — Date-wise 22ct & 24ct comparison
- 📈 **Weekly & Monthly bar charts** — Gold rate trend visualization
- 🏙️ **City selector dropdown** — Switch between major Indian cities (Mumbai, Delhi, Chennai, etc.)
- 📰 **Latest News section** — Gold & Silver related articles
- 🔗 **Cross-links** — Silver Rate & Petrol/Diesel price widgets
- 🗂️ **City index sidebar** — Quick links to 50+ city gold rates
- ❓ **FAQ accordion** — Q&A about gold investment in India
- 📱 **Fully Responsive** — Mobile & Desktop optimized



## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/your-username/gold-rate-today.git

# Navigate to project directory
cd gold-rate-today

# Install dependencies
npm install

# Start development server
npm start
```
